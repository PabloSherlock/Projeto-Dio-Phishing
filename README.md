# Projeto-Dio-Phishing
Teste de phishing educacional DIO.

usado atraves do kali linux

abrir console do kali e apos aberto, certificar de estar com acesso ROOT - sudo su

apos acessar com root, iniciar setoolkit

opção 1 - social engineering attacks

opção 2 - website attack vectors

opção 3 - credential harvester attack method

opção 2 - site cloner

apos entrar na opção site cloner, ele ira informar sobre o ip de acesso ao site falso e em seguida pedira qual o site que deve ser clonado.

como forma de teste, basta acessar o ip de acesso e o site clonado está lá, porem ao digitar senhas ou usuarios, as informações voltaram direto para o console  do kali

site clonado que foi usado para teste: http://www.facebook.com
